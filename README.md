# Домашняя работа 4
## Условие задачи
Два программиста, Анна (A) и Борис (B), дежурят ночью. Чтобы было не так скучно, они решили, что будут пить кофе только если кто-то один из них четный (по номеру своего рабочего места). Запишите условие для кофе-машины.
## 1. Алгоритм и блок-схемы
###Алгоритм:
1. Начало
2. Объявить переменные:
- **A** — номер рабочего места Анны.
- **B** — номер рабочего места Бориса.
3. Составить условие при помощи операторов if и else.
Анна и Борис будут пить кофе только в том случае, если ровно один из двух номеров рабочего места является чётным.
Условие открытия портала:

```c
((A % 2 == 0) && (B % 2 != 0)) ||
((A % 2 != 0) && (B % 2 == 0))
```
Если условие истинно, кофе-машина разрешает приготовить кофе. Если оба номера чётные или оба нечётные, кофе-машина не разрешает приготовить кофе.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    int A, B;

    puts("Введите номер рабочего места Анны:");
    scanf("%d", &A);

    puts("Введите номер рабочего места Бориса:");
    scanf("%d", &B);

    if (((A % 2 == 0) && (B % 2 != 0)) ||
        ((A % 2 != 0) && (B % 2 == 0)))
    {
        puts("Кофе разрешён!");
    }
    else
    {
        puts("Кофе не разрешён.");
    }

    return 0;
}
```
